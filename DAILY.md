# Daily Sources for Video Generation Research

A routine for keeping up with the field: what to check every day, what to check every week, and which
alerts to set up once. Links last checked on 2026-10-15.

Back to the [main page](README.md) · [Monthly updates](UPDATES.md)

## Every day (about 15 minutes)

### 1. New papers

| Source | What you get | Link |
|---|---|---|
| arXiv cs.CV, new | Most video-generation papers land here first (Sunday–Thursday evenings, US Eastern) | [cs.CV/new](https://arxiv.org/list/cs.CV/new) |
| arXiv search: "video generation" | Newest papers matching the phrase, across all categories | [search](https://arxiv.org/search/?query=%22video+generation%22&searchtype=all&order=-announced_date_first) |
| Hugging Face Daily Papers | Community-picked papers of the day, often with code and demos | [papers](https://huggingface.co/papers) |
| Hugging Face trending papers | What researchers are discussing this week | [trending](https://huggingface.co/papers/trending) |
| alphaXiv | arXiv with discussion threads on each paper | [alphaxiv.org](https://www.alphaxiv.org) |

Also worth a scan if you work on these areas:
[cs.GR](https://arxiv.org/list/cs.GR/new) (graphics, avatars, 3D/4D) ·
[cs.MM](https://arxiv.org/list/cs.MM/new) (multimedia) ·
[eess.IV](https://arxiv.org/list/eess.IV/new) (video processing) ·
[cs.SD](https://arxiv.org/list/cs.SD/new) (audio, video-to-audio) ·
[cs.RO](https://arxiv.org/list/cs.RO/new) (robotics world models).

## Set up once: alerts that come to you

| Tool | What to set up | Link |
|---|---|---|
| Google Scholar alerts | Alerts for key phrases ("video generation", "video diffusion", "world model") and for the citations of the seminal papers you follow | [alerts](https://scholar.google.com/scholar_alerts?view_op=list_alerts) |
| Scholar Inbox | Daily paper recommendations learned from papers you rate | [scholar-inbox.com](https://www.scholar-inbox.com) |
| Semantic Scholar | Research feeds and author alerts after you sign in | [semanticscholar.org](https://www.semanticscholar.org) |
| arXiv RSS | Put the cs.CV feed in any RSS reader | [RSS](https://rss.arxiv.org/rss/cs.CV) |
| GitHub "Watch → Releases" | Release notifications from the open-model repos above | — |
| Paper Digest | Daily digests by topic | [paperdigest.org](https://www.paperdigest.org) |
